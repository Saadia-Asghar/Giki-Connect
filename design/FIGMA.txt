GIKI-Connect — Figma (app UI, not the old proposal showcase)

1) Import the screen into Figma
   - Open Figma → File → Import (or drag onto canvas).
   - Choose: design/giki-app-figma.svg
   - Layers use the same names as the live app sections (Header, Card / Hobbies, etc.).

2) Preview in browser (same colors as the app)
   - From project folder:  pip install -r requirements.txt
   - Run:  python app_server.py
   - Open:  http://127.0.0.1:8765/design-preview
   - Live interactive app:  http://127.0.0.1:8765/

3) Tokens match web/styles.css (:root variables).

There is no Figma MCP in Cursor; import is always File → Import for SVG.
